# Currency exchange rates

Currency quotation project in Python utilizing APIs.

# 🚀 Features

 - 💱 Currency Quotation: Fetch real-time exchange rates for major currencies.
 - 🌐 Simple and User-Friendly: Easy-to-read currency conversion details.
 - ⚡ Powered by Python: Efficient and concise implementation.


# 🛠️ Tech Stack

- Python: The core programming language used for data handling and API integration.
- Requests Library: Facilitates communication with external APIs for fetching currency exchange rates.
- JSON: For parsing and processing the data received from APIs.
- Command-Line Interface: Ensures accessibility and simplicity for users to view real-time currency quotations.
